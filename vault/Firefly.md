# Firefly

A space where many AIs work together to build things.

- **Free first.** Easy work goes to free models (Llama and gpt-oss on Cloudflare, Hermes, free OpenRouter models). Paid models only get the hard jobs.
- **One dispatcher.** You tell the Lead; **JEV** hands each task to the right member by rules. JEV uses no AI, so it costs nothing.
- **One memory.** This vault. Open the `vault` folder in Obsidian to read and edit it; every member reads it.
- **Owner decides.** Money, keys, deleting things and changes to Firefly itself need the owner's yes.
