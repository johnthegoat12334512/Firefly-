# Improving Firefly

Firefly can improve itself, safely:

1. Any member can suggest an improvement. Add it under **Ideas** below with who suggested it and why.
2. The Critic and Checker review it in the chat.
3. A builder (an AI with access to the GitHub project) makes the change on its own branch and opens a pull request.
4. The tests must pass. The owner reads the summary and approves the merge. Nothing changes Firefly without that yes.
5. Afterwards, record what happened in [[Lessons]] and [[Decisions]].
